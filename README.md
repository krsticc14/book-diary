# Book Diary

A simple web application where users can search for books using an API
and add them to a personal reading diary with notes.

## Features
- Search books using Open Library API
- Add books to diary
- Delete books from diary
- Add personal notes
- Simple clean UI with styled header & footer

## Tech Stack
- Node.js + Express
- PostgreSQL (pg)
- EJS templates
- HTML / CSS

## Run the Project
1. Clone the repo
2. Install dependencies:
   npm install
3. Create a `.env` file and add your database credentials
4. Start the server:
   npm start
